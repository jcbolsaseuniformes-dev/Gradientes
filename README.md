# Gradiente SVG — preenchimento interativo (estilo CorelDRAW)

1. Envie a imagem e o SVG.
2. Na **imagem**, arraste uma linha para amostrar as cores (vira Gradiente N).
3. No **vetor**, clique na forma para aplicar o gradiente no mesmo ângulo (fountain fill).
4. Arraste os quadradinhos (alças) para ajustar. Esc cancela.
5. Baixe SVG (puro, `linearGradient` userSpaceOnUse) ou PNG.
